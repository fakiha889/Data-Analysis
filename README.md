# Data-Analysis
Data Analysis with Python

## Overview
This project demonstrates basic data analysis using Python, Pandas, and Matplotlib. It includes two tasks: laptop sales analysis and e-commerce sales and customer behavior analysis.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Task 1: Laptop Sales Analysis

This task analyzes laptop sales data and demonstrates basic data analysis techniques.

### Activities
- Handling missing values in weekly laptop sales data.
- Calculating total, average, and maximum sales.
- Storing laptop information using Python dictionaries.
- Performing operations on nested lists.
- Calculating discounted prices using functions.
- Classifying customer sentiment based on ratings.
- Creating bar charts to visualize weekly laptop sales.
- Generating a short executive summary.

## Task 2: E-commerce Sales and Customer Behavior Analysis

This task analyzes e-commerce data to understand sales performance and customer behavior.

### Activities
- Identifying missing values in the dataset.
- Filling missing customer ratings and marketing channels using the mode.
- Calculating total, average, and maximum sales.
- Using dictionaries and matrix operations.
- Calculating discounted product prices.
- Applying simple rating-based classification.
- Grouping sales by product category.
- Creating bar charts to visualize category-wise sales.
- Generating a short business summary.

## Tools and Libraries
- **Python:** Programming and data processing.
- **Pandas:** Data manipulation and analysis.
- **Matplotlib:** Data visualization.
- **Jupyter Notebook:** Writing and executing Python code.

## How to Run the Project

1. Download or clone this repository.
2. Install the required libraries:

   ```bash
   pip install pandas matplotlib notebook
   ```

3. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Open `project3--github.ipynb`.
5. Run the notebook cells.

## Dataset Requirements

Task 2 requires a CSV file named `ecommerce1.csv`. Make sure this file is available in the notebook's working directory before running Task 2.
